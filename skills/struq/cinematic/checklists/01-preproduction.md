# Preproduction Checklist

- [ ] The experience thesis is one coherent transformation.
- [ ] Required content is mapped to narrative actions, not only sections.
- [ ] The persistent-stage strategy is decided.
- [ ] Chapters have purposes, scroll budgets, and bridge ideas.
- [ ] Primary input ownership is explicit.
- [ ] Camera character and shot language are defined.
- [ ] Typography has a motion and layout system.
- [ ] Models contain or receive useful anchors.
- [ ] Every chapter boundary has a draft handoff contract.
- [ ] Desktop, mobile, and reduced-motion intent is documented.
- [ ] Asset readiness is mapped to chapter needs.
- [ ] Prohibited generic patterns are written down.
- [ ] One vertical slice is selected for the first implementation proof.
